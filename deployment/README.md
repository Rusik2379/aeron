# Размещение АЭРОН

Сервер: `lin-admin@100.105.206.103` (Tailscale). Каталог: `/opt/projects/aeron`.
Контейнер: `aeron-site`, порт `4186`, внешняя сеть Docker: `proxy-net`.
В Nginx Proxy Manager: `aeron.ru` → `http://aeron-site:4186`, загрузки до `16m`.

## DNS для директора

В действующей DNS-зоне aeron.ru заменить прежнюю A-запись корня `91.189.114.13`:

| Имя | Тип | Значение | TTL |
| --- | --- | --- | --- |
| @ | A | 128.0.27.134 | 300 |

Это замена прежней записи, а не добавление второго адреса. Если в панели имя заполняется полностью, указать `aeron.ru` вместо `@`.
На 02.11.2026 авторитетные DNS-серверы домена — nic.ru. Менять NS для этой операции не требуется.
Записи почты MX, SPF, DKIM, DMARC и остальные TXT оставить. IPv6/AAAA у нового сайта не настроен.
Адрес `100.105.206.103` служит для внутреннего доступа Tailscale, в публичный DNS его не добавлять.

После переключения DNS: Nginx Proxy Manager → Proxy Hosts → aeron.ru → Edit → SSL → Request a new SSL Certificate.
Выпуск сертификата и принятие условий провайдера выполняет владелец аккаунта. После выпуска включить Force SSL и HTTP/2.
Сайт и canonical настроены на `https://aeron.ru`. До выпуска сертификата настройка HTTPS не завершена.

## Админка

Общего пароля нет. По SSH на сервере выполните:

```sh
cd /opt/projects/aeron
bash deployment/setup-admin.sh
```

Пароль вводится без отображения и не записывается в исходники. Скрипт действует только при первом запуске и не заменяет существующий пароль.
После настройки HTTPS вход: `https://aeron.ru/admin/`.
Для почты: админка → «Заявки на почту», пароль внешнего приложения VK WorkSpace от `info@aeron.ru`.

## Эксплуатация

```sh
cd /opt/projects/aeron
docker compose ps
docker compose logs --tail 100
docker compose up -d --build --wait
```

`runtime/data` содержит рабочий контент, пароль админки, закрытые настройки SMTP и автоматические копии контента.
`runtime/uploads` содержит пользовательские фотографии. Сохранять резервные копии обеих папок вне контейнера.
Каталоги сохраняются при пересоздании контейнера. Не включать `runtime` в Git или Docker-образ.
Начальные материалы из `data/content.json` копируются только при первом запуске; последующие сборки не заменяют рабочие данные.

`AERON_TRUSTED_PROXIES` содержит конкретный IP контейнера Nginx Proxy Manager в `proxy-net` — `172.18.0.2`.
Если адрес прокси изменится, обновить его в compose.yaml и пересоздать контейнер сайта. От произвольных клиентов заголовки адреса посетителя не принимаются.
